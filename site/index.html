How Nacho Flow Works

Deterministic control over every prompt turn in 3 simple steps.

1

Point Your Agent Harness

Change your API Base URL to http://localhost:8000/v1 in Zoo Code, OpenCode, Aider, or Cline. Nacho Flow speaks standard OpenAI API wire format.

2

Set Policy in 10 Lines of YAML

Define simple routing rules in config.yaml using token bounds (Tokens < 8000), turn retries (Retries < 2), or domain keywords (deadlock, architecture).

3

Enjoy $0.00 Local Turns

Routine iterative turns stay on your workstation GPU for free, with automatic seamless escalation to flagship cloud models when reasoning demands it.

3-Tier Curated Intelligence (OTA)

Reasoning Stream Normalizer

Intercepts thinking tokens from DeepSeek-R1, QwQ, Qwen 2.5, and Claude, converting them into standard <think> tags on the fly.

Local Circuit Breaker & 0ms Failover

Detects when local Ollama/vLLM hangs or runs out of VRAM, immediately diverting turns to cloud with zero dial delay.

🔄

Retry-Based Auto-Escalation

Tracks session retries in a sliding 5-min TTL. If an agent loops on a local model, Nacho Flow escalates to Claude on Turn Retry 2.

📏

Adaptive Token EMA Calibrator

Dynamically recalibrates character-to-token ratios using Exponential Moving Average to prevent context undercounting on code.

🛡️

Delayed SSE Header Quality Guard

Holds back HTTP 200 headers on streams until peeking valid data, enabling cloud failover on empty or broken local payloads.

🎸

Cycle Killer (Qu'est-ce que c'est?)

In-flight stream defense that murders infinite repetition loops (<3s) and runaway prose monologues before they burn your GPU, transparently retrying or escalating without stalling.

⚡

Kickstart Resuscitation

Detects semantic stalls and multi-turn idle loops (e.g. repeated read_file churn) and injects authoritative system nudges or escalates to frontier models (SessionKickstarted) with write-only tool filtering.

🧚

Fairy Dusting (Proactive Checkpoints)

Periodically and transparently routes turns to frontier reasoning models on a configurable write-progress cadence (e.g. every 15 file writes) with injected audit directives to catch subtle bugs before they cascade.

🛡️

Agentic Tool Fallback Shield

Sliding tail-buffer analysis (4.67ns, 0 allocs) detects conversational plans/questions from local models in Zoo Code/Cline and synthesizes ask_followup_question tool calls to eliminate 3-strike crashes.

🛠️

Universal Tool Calling Normalizer

Converts 8 tool-calling format families (Hermes, Mistral, Llama 3, Claude XML, ReAct) into standard OpenAI tool_calls JSON.

🎛️

Cost-Penalty Auto-Tuner CLI

Run nacho-flow tune to perform statistical odds-ratio grid search on your historical logs and generate optimal rules.

🌶️

HotSauce Directives (In-Prompt Routing)

Splash heat onto prompt turns to override routing (@nacho:local, @nacho:cloud, @nacho:reasoning, @nacho:tier="...") or query daemon metadata (@nacho:help, @nacho:tiers, @nacho:deals) with < 7ns zero-alloc bailout and zero LLM cost.

📐

Context Window Boundary Guard

O(1) pre-guard checks model physical context limits, preventing 400 Context Length Exceeded errors before they happen.

🧩

Real-Time IDE Control & Live Telemetry

Powers the official VS Code extension with zero-polling SSE live metrics, real-time financial telemetry, and instant daemon controls.

🎛️

Per-Tier Stream Policies

Selectively toggle tool-call normalizers, thinking-token formatters, and fallback shields per tier in config.yaml to tailor proxy behavior for specific models.

💰

Prompt Cache-Aware Cost Engine

Ingests upstream provider prompt caching discounts (~80% off prompt tokens from OpenRouter / DeepSeek) with a 3-tier priority oracle for dollar-accurate accounting.

🛡️

In-Prompt Stream Bypass

Add @nacho:raw for transparent, unadulterated SSE byte streams with zero proxy rewriting, or @nacho:no-shield for automated headless scripts without interactive prompt synthesis.
