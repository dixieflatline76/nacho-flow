🛡️ Active Runtime Supervisors

Four real-time stream interceptors that stabilize local GPUs and budget cloud models—killing runaway loops, normalizing malformed tool tags, unsticking stalled plans, and checkpointing logic.

🎸 IN-FLIGHT STREAM BREAKER 🎸

Cycle Killer (Qu'est-ce que c'est?)

Kills circular inner monologues and runaway hallucination loops.

❌ Why cheap models fail: Trapped in endless <think> deliberation and runaway rants that burn tokens while your IDE sits frozen.

Monitors live SSE streams with 3-lane isolation (thinking vs. prose vs. tools). Slices through repetitive loops in <3s and injects a local $0.00 steer prompt to force an immediate tool action without aborting your agent session.

🛠️ AGENT HARNESS SHIELD 🛠️

Tool Normalizer

Stops 3-strike harness crashes before they abort your run.

❌ Why cheap models fail: Omitting closing XML tags or outputting conversational chatter instead of raw JSON tools.

Translates between XML and JSON on the fly, auto-closes unclosed tool tags (</write_to_file>), and repairs hallucinated parameters so Cline, Zoo Code, and OpenCode never crash.

⚡ STALL RESUSCITATION ENGINE ⚡

Kickstart

Tells the AI to continue when the job is not yet done.

❌ Why cheap models fail: Analysis paralysis—spinning in 10-turn read-only planning loops without writing code.

Monitors consecutive non-write turns. When an agent stalls, Kickstart bursts a single turn to a frontier brain to unstick execution, then immediately hands control back to your cheap model.

🧚 PROGRAMMABLE CHECKPOINTS 🧚

Fairy Dust

Sprinkles in frontier brains at critical quality milestones.

❌ Why cheap models fail: Subtle logic bugs and silent // TODO stubs that compound into wreckage.

A cadenced audit harness. Deploys frontier reasoning models (Claude, DeepSeek-R1) every N writes to audit code and catch logic drift before errors compound—without running expensive models all day.

🧪 EXPERIMENTAL LABS / OPT-IN RESEARCH
OPT-IN HEURISTIC COMPACTION

🧪 Nacho Labs: Experimental Context Compactor (NTS)

An opt-in research pipeline exploring long-context token reduction. Kept disabled out-of-the-box so users experience rock-solid cache stability, zero diff drift, and maximum prompt cache savings.

🧹 TERMINAL SANITIZER (OPT-IN) 🧹

ANSI & Spinner Purge

Purges progress spinner garbage and terminal spam in-place.

Terminal commands spit out thousands of raw ANSI escape sequences, spinner animations (|/-\), and carriage returns (\r). NTS purges them cleanly in-place with zero heap allocations when enabled.

📑 STALE READ COMPACTOR (EXPERIMENTAL) 📑

Superseded Read Compaction

Folds stale file-reads once a file is edited or re-read.

When an agent inspects the same 1,000-line file across 20 turns, older reads become dead weight. NTS provides configurable depth-based compaction into structural notices for developer evaluation.

🛡️ HARNESS SHIELD (EXPERIMENTAL) 🛡️

IDE Boilerplate Pruning

Strips repetitive extension notices and runaway diff dumps.

Harnesses like Cline and Zoo Code inject multi-line <notice> hints and massive search blocks on diff misses. NTS provides experimental rules to prune harness noise on request.

📐 WHITESPACE NORMALIZER (EXPERIMENTAL) 📐

Whitespace & Blank Line Pruning

Collapses runaway blank lines and duplicate noise bursts.

Long test runs and build outputs often leak hundreds of blank lines. This pass normalizes consecutive newlines and deduplicates repeating chunks with zero memory allocation.
