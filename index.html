How Nacho Flow Works

Deterministic control over every prompt turn in 3 simple steps.

1

Point Your Agent Harness

Change your API Base URL to http://localhost:8000/v1 in Cursor, Roo Code, Cline, or Aider. Nacho Flow speaks standard OpenAI API wire format.

2

Set Policy in 10 Lines of YAML

Define simple routing rules in config.yaml using token bounds (Tokens < 8000), turn retries (Retries < 2), or domain keywords (deadlock, architecture).

3

Enjoy $0.00 Local Turns

Routine iterative turns stay on your workstation GPU for free, with automatic seamless escalation to flagship cloud models when reasoning demands it.

Engineered for Autonomous Coding

Production-hardened resilience tested across 350,000+ requests.

⚡

< 0.36ms Low Latency Core

Handles 30,800+ req/s with lock-free atomic RCU router state and pre-pooled HTTP transports.

🧠

Reasoning Stream Normalizer

Intercepts thinking tokens from DeepSeek-R1, QwQ, Qwen 2.5, and Claude, converting them into standard <think> tags on the fly.

🚦

Local Circuit Breaker & 0ms Failover

Detects when local Ollama/vLLM hangs or runs out of VRAM, immediately diverting turns to cloud with zero dial delay.

🔄

Retry-Based Auto-Escalation

Tracks session retries in a sliding 5-min TTL. If an agent loops on a local model, Nacho Flow escalates to Claude on Turn Retry 2.

📏

Adaptive Token EMA Calibrator

Dynamically recalibrates character-to-token ratios using Exponential Moving Average to prevent context undercounting on code.

🛡️

Delayed SSE Header Quality Guard

Holds back HTTP 200 headers on streams until peeking valid data, enabling cloud failover on empty or broken local payloads.

🛠️

Universal Tool Calling Normalizer

Converts 7 tool-calling format families (Hermes, Mistral, Llama 3, Claude XML, ReAct) into standard OpenAI tool_calls JSON.

📐

Context Window Boundary Guard

O(1) pre-guard checks model physical context limits, preventing 400 Context Length Exceeded errors before they happen.

🎛️

Cost-Penalty Auto-Tuner CLI

Run nacho-flow tune to perform statistical odds-ratio grid search on your historical logs and generate optimal rules.
