You can verify the generated code, test coverage, and race condition guarantees on your local machine using standard Go tooling (requires Go 1.22+):

### 1. Run Unit Tests with Race Detection & Coverage
```bash
go test -race -cover ./...
```
Expected output:

## Why Agent Supervision Was Required

Open-weight models like GLM-5.3-Flash, Qwen 2.5/3.8 Coder, and DeepSeek are capable coders, but autonomous harnesses frequently fail when running them due to three common failure modes:

1. **Chain-of-Thought Death Spirals:** On Turn 1 of this run, the model attempted to enter a repetitive thinking loop during initial architecture planning. Nacho Flow's **Cycle Killer** detected the cyclic n-grams in the streaming SSE chunks, terminated the stream in under 3 seconds, and injected a clean recovery prompt. The model recovered immediately on Turn 2, created [`plans/blackjack_plan.md`](plans/blackjack_plan.md), and began generating code.
2. **Context Bloat & Cache Busting:** Autonomous agents re-read terminal output and file diffs on every turn. Nacho Flow's **Prompt Cache Protection** preserved strict byte-level prefix determinism across all 57 turns, achieving 80%+ KV cache reuse on OpenRouter and keeping total API cost under $0.70.
3. **Malformed Tool Execution:** When models drop closing XML tags or hallucinate parameter keys, Nacho Flow's **Tool Normalizer** intercepts and repairs the payload on `127.0.0.1` before the harness triggers a strike error.

For more details on the supervision architecture and VS Code extension, see the main [Nacho Flow Repository](https://github.com/dixieflatline76/nacho-flow).
