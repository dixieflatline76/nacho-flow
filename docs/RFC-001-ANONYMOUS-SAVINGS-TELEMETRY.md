* **Status**: Proposed / Future Milestone

## 1. Executive Summary

This RFC outlines the technical design for an **opt-in, privacy-preserving, zero-PII community telemetry system** for Nacho Flow. 

The goal is to calculate cumulative real-world dollar savings generated by Nacho Flow across global installations and display a verified, real-time social proof counter on the website/documentation hub (e.g. `💰 $2,847,312 saved from cloud bills across 4,800+ instances`).

```
+---------------------------+       +---------------------------+
|    Local Nacho Flow       |       |   Central Counter API     |
|   (Runs on Workstation)   |       |   (Cloudflare Worker)     |
+---------------------------+       +---------------------------+
              |                                   |
    Calculates Local vs Cloud                     |
    Savings per Turn ($0.00 vs $2.00)             |
              |                                   |
    Aggregates Weekly delta (e.g. +$4.20)         |
              |                                   |
    Sends Blind Opt-In Ping --------------------> | Adds delta to global
    (Zero IP, Zero ID, Zero Payload)              | Redis/KV counter
                                                  |
                                                  v
                                    +---------------------------+
                                    |    nacho-flow Website     |
                                    |    Live Social Proof      |
                                    +---------------------------+
```

## 2. Privacy & Threat Model Guarantees

To ensure full open-source community trust, the telemetry mechanism must adhere to the following **Zero-Data Invariants**:

1. **Zero Content Inspection**: Prompts, completions, tool call arguments, file paths, and model names are never collected or transmitted.
2. **Zero Persistent Machine Identity**: No hardware GUIDs, MAC addresses, hostnames, usernames, or persistent device hashes are generated or attached.
3. **No IP Address Logging**: The backend aggregator (e.g., Cloudflare Worker / Edge function) discards client IP addresses immediately without writing access logs.
4. **Differential Privacy / Jitter**: Pings are sent on a randomized weekly timer with ±24h jitter so timing cannot correlate to user activity patterns.
5. **Strict Opt-In Default**: Explicitly configured in `config.yaml` or prompted clearly on first interactive CLI setup.

## 3. Local Data Collection Specification

### 3.1 Local Calculation Logic

Nacho Flow already calculates the pricing differential for every routed turn:
```go
// savings = what cloud provider would have billed - what local provider billed ($0.00)
turnSavingsUSD := (inputTokens * cloudInputRate) + (outputTokens * cloudOutputRate)
```

Locally, Nacho Flow maintains an encrypted/atomic delta counter in `~/.nacho-flow/state.json`:
```json
{
  "unreported_savings_cents": 1420,
  "last_telemetry_ping_unix": 1787350000
}
```

### 3.2 Wire Payload Format

When a weekly window triggers, Nacho Flow transmits a minimal payload:

```http
POST https://telemetry.nacho-flow.dev/v1/savings/report
Content-Type: application/json

{
  "version": "0.5.1",
  "savings_cents": 1420,
  "turns_local": 48,
  "turns_escalated": 17
}
```

*Note: Notice there is no user token, no API key, and no machine identifier.*

## 4. Aggregator & Counter Architecture

### 4.1 Edge Worker (`api.nacho-flow.dev`)
- Built on Cloudflare Workers / Deno Deploy + Cloudflare KV / Upstash Redis.
- Implements an atomic counter:
  ```typescript
  export default {
    async fetch(request, env) {
      if (request.method === "POST") {
        const data = await request.json();
        const cents = Math.max(0, Math.min(1000000, Number(data.savings_cents) || 0));
        
        // Rate limit: Max reasonable single ping to prevent spam/skew
        if (cents > 0) {
          await env.KV.put("global_savings_cents", currentTotal + cents);
          await env.KV.put("global_instances_active_30d", instancesCount);
        }
        return new Response(JSON.stringify({ status: "ok" }));
      }
      
      // Public GET endpoint for website badge
      if (request.method === "GET") {
        const total = await env.KV.get("global_savings_cents");
        return new Response(JSON.stringify({ total_usd: total / 100 }));
      }
    }
  }
  ```
