## 1. Executive Overview

Between `v0.5.2` and `v0.6.0`, Nacho Flow evolved from a high-throughput command-line AI routing proxy into a **complete AI developer routing platform**. This release introduces:
- The **official VS Code Companion Extension** featuring an Activity Bar sidebar control hub, status bar telemetry, and an interactive full-page analytics webview.
- A **Management REST API** (`/v1/mgmt/*`) enabling live stats recalculation, runtime counter resets, and circuit breaker management.
- An **8-Format Multi-Model Tool Call Normalizer Pipeline** translating heterogeneous LLM XML/JSON tool responses into standard OpenAI JSON schemas.
- **In-Prompt Directives (HotSauce)** allowing developers and autonomous agents to steer routing tiers via `@nacho:*` tags.
- **Heat Seeker Live Model Deals**, dynamically detecting price drops across 300+ frontier models.
- **Zero-Maintenance Automated Versioning CI/CD** tied to `version.txt`.

## 2. VS Code Companion Extension Suite

The VS Code Companion Extension (`nacho-flow-v0.6.0.vsix`) provides an integrated control plane directly inside the editor.

### 2.1 Architectural Principles (Thin-Client Doctrine)
- **Zero Core Routing Logic in TypeScript**: All prompt token estimation, `expr` rule evaluation, circuit breaker logic, and financial telemetry reside in the compiled Go daemon.
- **REST + SSE Communication**: Communicates with the daemon via REST endpoints for command actions and Server-Sent Events (`GET /v1/events`) for zero-polling real-time updates.
- **Local & Remote Daemon Support**: Supports both local bundled binaries and remote server instances over LAN or Tailscale.

### 2.2 Core Components & Subsystems
1. **`ProcessManager` (`src/core/process-manager.ts`)**:
   - **3-Tier Binary Resolution**: Bundled platform binary (`extension/bin/nacho-flow*`) $\rightarrow$ Workspace binary (`./bin/nacho-flow`) $\rightarrow$ System `PATH`.
   - **Lifecycle State Machine**: Start, Stop, and Restart transitions with atomic status updates.
   - **Live Log Streaming**: Captures daemon `stdout` and `stderr` and streams them into a dedicated VS Code Output Channel (`🌮 Nacho Flow Engine`).
2. **`AuthManager` (`src/core/config/auth-manager.ts`)**:
   - **Isolated Local vs Remote Persistence**: Switching between **This Machine** (`http://127.0.0.1:8000`) and **Remote Server** (`http://<ip>:8000`) keeps settings strictly isolated.
   - **Secure Token Storage**: Persists Bearer tokens in `vscode.SecretStorage` and URL preferences in `context.globalState`.
3. **Sidebar Control Hub (`src/ui/sidebar/sidebar-view-provider.ts`)**:
   - **Engine Control**: One-click Start / Stop / Restart buttons with stateful glass styling.
   - **Upstream Inference Engine Discovery**: Real-time status chips and tier model discovery for Ollama, OpenRouter, vLLM, SGLang, and llama.cpp.
   - **Action Pills**: Hardware VRAM Specs modal, official binary download link, and API key management.
   - **One-Click Agent Copy**: Quick copy helpers for `Base URL`, `API Key`, and `Model ID` (`nacho-hybrid`) for Roo Code, Cline, and Cursor.
   - **Danger Zone & Maintenance**: Recalculate stats from server logs, Reset tripped circuit breakers, Reset stats to $0.00.
   - **Direct Help & Support Links**: Distinct buttons for User Guide (`docs.html?doc=user_guide`) and Support portal (`support.html`).
4. **Status Bar & Rich Hover Card (`src/ui/status-bar/item.ts`)**:
   - High-visibility status bar item (`🌮 $X.XX svd`) with live updates.
   - Rich Markdown hover tooltip displaying engine status, uptime, total savings, and provider circuit states.
5. **Real-Time Analytics Dashboard Webview (`src/ui/webview/dashboard.ts`)**:
   - **Live Financial Cards**: Total Spend, Total Savings, Savings %, and Total Request Count.
   - **O(1) Rolling Time Windows**: Today, This Week, This Month, and All-Time.
   - **Live Route Inspector**: Inspects the last 500 requests in-memory with zero disk I/O latency.
   - **Interactive Circuit Breaker Manager**: Live status cards with individual reset buttons.
   - **Configuration Editor**: Hot-reloads `config.yaml` with live syntax validation.
   - **Autonomous Auto-Tuner Trigger**: Launches `nacho-flow tune` empirical optimization directly from the webview.

## 3. Backend Management REST API & Daemon Telemetry

To support GUI clients and orchestration tools, the Go daemon exposes dedicated management endpoints under `/v1/mgmt/*` protected by Bearer authentication:

### 3.1 Endpoints Specification
| Method | Endpoint | Description | Request Body | Response |
| :--- | :--- | :--- | :--- | :--- |
| `POST` | `/v1/mgmt/stats/recalculate` | Re-reads disk traffic logs (`traffic.jsonl`) and recomputes cumulative savings and metrics. | None | `{"status": "ok", "message": "Statistics recalculated", "stats": {...}}` |
| `POST` | `/v1/mgmt/stats/reset` | Atomically zeroes out runtime financial metrics counters. | None | `{"status": "ok", "message": "Statistics reset successfully"}` |
| `GET` | `/v1/mgmt/circuits` | Returns real-time health and trip counters for all upstream provider circuit breakers. | None | `{"circuits": [{"provider": "openrouter", "state": "closed", ...}]}` |
| `POST` | `/v1/mgmt/circuits/reset` | Closes a tripped circuit breaker to resume upstream traffic. | `{"provider": "openrouter"}` | `{"status": "ok", "message": "Circuit breaker reset", "provider": "openrouter"}` |

### 3.2 High-Performance Telemetry Subsystems
- **O(1) Rolling Time Windows (`pkg/telemetry/metrics.go`)**:
  - `StatsTracker` maintains atomic accumulators for **Today**, **Week**, **Month**, and **All-Time** without iterating historical records.
- **In-Memory Ring Buffer Sink (`pkg/telemetry/ring_buffer.go`)**:
  - Non-blocking circular buffer retaining the last 500 request turns in memory with 0ms disk overhead.
- **SSE Real-Time Event Broker (`pkg/telemetry/events.go`)**:
  - Subscribable event broker broadcasting `stats_update`, `route_record`, `circuit_trip`, and `circuit_reset` over `/v1/events`.

## 4. 8-Format Multi-Model Tool Normalizer Pipeline

Local and open-weights models (e.g. Qwen 2.5, DeepSeek-R1, Mistral, Command-R) frequently emit tool calls as embedded text instead of standard OpenAI JSON schema. Nacho Flow intercepts and normalizes 8 distinct formats:

1. **Bare JSON**: Text responses containing raw JSON function call payloads.
2. **Markdown JSON Code Fences**: ` ```json\n{"name": "...", "arguments": {...}}\n``` `.
3. **Hermes / Claude XML Tags**: `<tool_call>\n{"name": "...", "arguments": {...}}\n</tool_call>`.
4. **Mistral Array Calls**: `[{"name": "...", "arguments": {...}}]`.
5. **DeepSeek-R1 Reasoning + Tool**: Extracts `<think>...</think>` into `reasoning_content` while promoting embedded tool invocations to standard `tool_calls`.
6. **Llama 3 Tool Syntax**: `<|python_tag|>` function call formats.
7. **Custom Function Objects**: `[CALL func_name(arg=val)]` patterns.
8. **Standard OpenAI Passthrough**: Verifies existing `tool_calls` structures.

## 5. 🌶️ HotSauce Directives & Zero-Cost Meta Command Engine

Developers and coding agents can steer routing dynamically inside prompts using `@nacho:*` tags.

### 5.1 Dynamic In-Prompt Directives
- `@nacho:tier <name>`: Forces routing to a specific named tier in `config.yaml`.
- `@nacho:force <provider>`: Overrides provider selection (e.g. `@nacho:force ollama`).
- `@nacho:heat <mild|medium|spicy|fire>`: Applies spot deal price-to-performance bias.

### 5.2 Zero-Cost Meta Commands
Meta commands execute completely in-process within the Go daemon with **$0.00 cost** and **0 upstream tokens consumed**:
- `@nacho:help`: Returns instant Markdown quick-start guide.
- `@nacho:tiers`: Displays active tier definitions and routing rules.
- `@nacho:status`: Returns live uptime, circuit breaker states, and savings.
- `@nacho:deals`: Returns live curated model deals and flash discounts.

### 5.3 Performance & Safety
- **SIMD Fast Bailout**: Benchmark verified at **6.29 nanoseconds** with **0 B/op heap allocation** for normal non-directive prompts.
- **Levenshtein Typo Matcher**: Suggests closest valid tag for minor misspellings.
- **Anti-Abuse Debounce**: Caches repeated queries within 2 seconds to prevent agent recursion loops.

## 6. 🔥 Heat Seeker: Live Model Deals & Price Drops

Nacho Flow continuously evaluates model pricing to identify flash discounts and free tier endpoints:
- **Lock-Free Pricing Oracle (`pkg/telemetry/pricing.go`)**: $O(1)$ lock-free lookup ($< 40\text{ ns}$) using atomic pointer swaps.
- **Quality-to-Price Discovery**: Computes price-performance ratios across 300+ models in memory in $< 45\mu\text{s}$.
- **One-Click Adoption**: The VS Code dashboard allows users to adopt deals into `config.yaml` with YAML comment preservation.

## 7. Diff Sanitizer & Response Normalization

When local models emit markdown diff blocks (e.g. ` ```diff ... ``` `) with improper prefix markers or malformed header lines, agent file editors (such as Roo Code or Cline) can fail during patch application.
- **`pkg/router/diff_sanitizer.go`**: Validates diff blocks, cleans up malformed headers, standardizes hunk markers, and guarantees clean file application.
